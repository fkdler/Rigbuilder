# 模型意图与产品资料优化

## 反馈与根因

“本地部署量化模型，推荐一个”被回答成 Ryzen 处理器；用户纠正后又变成处理器介绍。原规划只允许 CPU/GPU 目标，提示词和紧凑选择协议也以硬件为中心。模型缺乏表达 AI 模型对象的通道，产品介绍还会在没有明确指代时拿上一轮硬件补空对象。

“介绍 5090D”没有显示显存等已有资料。真实数据库的 GpuSpec 已收录 Blackwell、32 GiB、GDDR7、575 W，但 accepted evidence 只有两条产品名称证据。旧实现把缺少字段证据等同于完全没有可展示资料。

## 当前实现

- 意图计划新增 `domain=hardware/ai_model/general`、`roles=model`、`workload=local_ai`。分发使用 `temperature=0`，减少分类随机波动；用户的购买对象与已有资源分开处理。
- 两路 Agent 仍分别选择并提交模型候选，走既有真值核验及融合；模型请求限定 ai_model 类型，硬件不能通过类别门禁。已指定的型号、量化条件和资源筛选为空时，不再让模型自行放宽或替换为硬件。
- 模型查询读取模型目录、量化下载记录和带限定条件的部署属性。有硬件资源时先缩小候选，缺少资源时给出暂定候选并询问缺失项；不重复索要已经提供的条件。默认候选政策为常见个人机规模的指令模型，默认参考 Q4_K_M；这是起点而非能力排行榜。
- “我要的是模型，不是配置”明确改回模型推荐；“买显卡来部署模型”仍买显卡；“配电脑跑模型”仍配电脑。“更小一点”缩小规模；新的明确型号覆盖旧的模糊规模偏好；Q8_0 覆盖 Q4_K_M，保留其他资源条件。
- 产品介绍同时展示规格与证据状态。通过 TruthVerifier 的字段标“已核验”；规格表存在但没有足够证据的字段标“目录收录 · 待补证据”。来源注明支持的字段，名称证据不能冒充显存证据。没有明确指代时不再用旧 CPU 填空。
- 模型推荐展示模型标题、基础规格、量化下载参考与对应条件的加载估计。下载记录不代表已验证文件或运行兼容性；加载估计不等于总显存、更不等于实测速度。

## 数据边界

5090D 规格未被写成新的数据库证据；本轮没有修改目录真值或提高 evidence review_status。其 32 GiB、GDDR7、575 W 来自已有规格表；NVIDIA 系列页与第三方索引当前只支持产品名称。

部分 `model.deployment_*` 字段定义要求区间比较，实际存储却是标量估计，TruthVerifier 返回 `canonical_range_invalid`。本轮没有放宽全局核验器。仅将同实体、字段、单位、数值匹配的 accepted 来源与当前量化条件的目录值展示为“来源估计，尚未完整核验；非本机实测”。没有匹配来源的估计不展示；API 条件不作为本地部署数据。

量化版本目录中的 `recommendable=false` 记录不会被改成核验通过的推荐实体。推荐实体是已核验的基础模型；版本及下载地址作为明确标记的目录参考，运行条件仍需确认。

## 验证记录

真实测试访问已授权的数据库及 `<DEVICE_B_IP>:8081/8082`，每轮创建独立普通账号与对话，退出时撤销 token。证据保存在忽略目录 `.local-logs`，不提交账户令牌。

- `model-intent-first.json`：原问题、硬件转模型纠错、带显卡资源的模型请求及介绍。
- `model-intent-greedy.json`：更小模型、固定 Qwen3-8B、Q4→Q8、5090/5090D 介绍及购买显卡的最终回放。
- `model-target-browser.json`：真实浏览器的资料展示和目标纠错。
- `product-5090d-*.png`、`model-recommendation-*.png`：桌面／移动端截图。

历史文档中较早的通过数量与样本仅代表当时版本；本报告末尾记录最终检查结果。

最终八轮回放均符合预期：普通量化推荐约 5.9 秒（Llama-3.1-8B-Instruct）；更小模型约 6.5 秒（Llama-3.2-3B-Instruct）；固定 Qwen3-8B 约 5.0 秒；Q4→Q8 约 4.5 秒且保留已知资源；5090 与 5090D 介绍各约 1.1 秒；购买显卡约 4.5 秒；纠正为模型约 7.9 秒。推荐场景两路 Agent 全部 completed。单次采样仅用于功能验收，不是性能基准。

额外验证“1GB 显存，必须 Qwen3-8B Q8_0”：约 1.3 秒说明当前条件下没有证据匹配的候选，没有推荐替代模型或硬件（`model-no-match-result.json`）。真实浏览器四轮对话与桌面／移动布局验收通过，无页面异常。

后端完整回归 494 passed、5 skipped；前端 164 项单元测试及生产构建通过。文档相对链接检查与 `git diff --check` 通过。修改尚未提交。
