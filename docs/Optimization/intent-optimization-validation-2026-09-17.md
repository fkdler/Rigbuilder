# 单件推荐、意图规划与产品介绍验收

基于 `5b808ca` 及现有未提交修改继续优化。没有修改目录真值数据；联调创建独立普通测试账号、会话和任务，测试结束撤销登录 token。

## 改动

- agent-b 输出短执行计划（任务、单件/整机范围、目标类别、用途、偏好、介绍对象、是否延续）。所有规划字段均要求输出，最多 320 tokens。计划注入后续检索和模型选择，而非让分发器写产品事实或 SQL。
- GPU/CPU 单件检索限定对应类别和桌面候选；整机仍核验两种核心角色及其配对。当前有效请求取代旧回答，新的完整推荐不继承旧型号。明确指代“这张显卡”时才绑定已核验的上一轮选择。
- 补齐整机追问范围一致性保护，避免 `continues_build=true` 同时误标为单件。精确型号 SQL 在配对之前区分 RTX 5070 与 Ti、5090 与 D、14700K 与 KF，防止宽松匹配得到错误 CPU 候选。
- 未指定型号时，候选检索优先要求规格的 accepted evidence，避免落到只有名称证据的条目后再进行多轮模型补查。指定型号不加此条件，不能因为资料少而擅自替换。
- “介绍”独立查询本地产品目录和规格证据，经 TruthVerifier 过滤后直接显示介绍与资料来源，不进入双模型推荐或推荐模板。这是本地资料检索，未接入实时外网搜索。
- 推荐内容移除存储、散热、机箱及其缺失提示；硬件名称使用 `#D97757`。Spinner 为 `· ✢ ✳ ✶ ✻ ✽` 往返，保持真实耗时与真实流式用量。

## 实机与浏览器

端点：`<DEVICE_B_IP>:8081`（agent-a，约 8.19B Q4_K_M）、`:8082`（agent-b，约 4.21B Q6_K）。中途设备关机导致连接超时；用户恢复设备后重测。连接故障记录不计入验收或速度比较。

同样六轮问题的任务耗时如下（秒，后端 started_at → completed_at；各取一次，非性能基准）：

| 问题 | 修改前 | 修改后浏览器验收 | 结果 |
| --- | ---: | ---: | --- |
| 推荐一个特别好的 GPU | 30.485 | 5.772 | 仅 RTX 5090，无整机列表 |
| 推荐一套普通打游戏的配置 | 5.878 | 8.212 | RX 6600 XT + Ryzen 5 5600F |
| 重复普通游戏配置 | 7.192 | 5.488 | 完整 CPU/GPU；不继承旧高端要求 |
| 介绍一下 RTX 5090 | 5.740 | 0.901 | 规格介绍及来源，无推荐模板 |
| 只推荐适合游戏的显卡，不要整机 | 7.424 | 6.306 | 仅显卡，无 CPU/配套列表 |
| 给这张显卡配一套主机 | 8.784 | 7.339 | 绑定上一轮 RX 6700 XT，补齐 Ryzen 5 9600X |

修改前第一行包含一路 Agent 失败，不能将该差值解读成正常场景的加速倍数。修改后以上推荐请求的两路 Agent 均 completed；介绍无需调用推荐 Agent。普通整机时延有波动，本轮主要加速来自有界候选检索和介绍专用路径。

扩展七轮场景覆盖“不含一个的显卡请求”、显卡→整机、RTX 5090→5070 覆盖、CPU 单件、游戏整机→50 系追问。最终一轮中，5070 追问得到 RTX 5070 + Core i7-14700KF；CPU 单件得到 Core i5-12400。所有推荐请求两路 Agent 均成功，各只需一次候选选择调用。50 系追问在加入规格证据筛选前曾耗时 43.942 秒（反复补查只有名称证据的条目），最终为 7.469 秒，得到 RTX 5070 + Ryzen 5 5600F；显卡与 CPU 仍通过原有配对政策核验。

浏览器真实捕获了 `✻ Cooking… (2s · ↑ 30 tokens)`，采样观察到全部六种符号与增长的 token 数。token 来自服务端实时输出统计；当前值是活跃调用之和，不是任务累计，调用结束时可下降或隐藏。仅最终 usage 不伪装成实时计数。最终答案仍在核验、融合完成后显示。

## 验证与证据

- 前端 162 项单元测试、生产构建通过。
- 实机浏览器六轮对话测试通过；包含两路 Agent 成功、单件/整机、介绍来源、硬件颜色、移除项、无页面异常及移动端横向溢出检查。
- 桌面/移动端流式状态浏览器回归共 2 项通过，覆盖多调用计数与切换会话清理。
- 后端完整回归 484 passed、5 skipped；使用工作区 `--basetemp`，避开 Windows 系统临时目录权限问题。
- 本轮未重跑全部历史 E2E；上轮记录的旧标签断言失败不在此次通过范围内。
